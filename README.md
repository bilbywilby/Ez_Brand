# Brand Guidelines — DevHound

**Last Updated:** August 5, 2026

## Overview

DevHound is an open-source project with a distinctive husky mascot featuring a triangular collar tag bearing the letter **D**. These guidelines ensure consistent, respectful use of our branding across all contexts.

## Logo Description

### Official Logo Components

| Element | Description |
|---|---|
| **Mascot** | Stylized husky/alaskan malamute head in profile view, black-and-white line art |
| **Collar** | Triangular pendant tag hanging from neck, centered on chest area |
| **Letter Mark** | Capital **D** engraved on triangular collar tag, pointing downward |
| **Style** | Vector line art, high contrast black on white background |

## Usage Rules

### ✅ DO

| Guideline | Specification |
|---|---|
| **Use approved assets** | Only use official logos from `/assets/logo/` directory |
| **Maintain contrast** | Keep black-on-white or white-on-black for optimal legibility |
| **Preserve proportions** | Scale uniformly without distorting aspect ratio |
| **Include clear space** | Maintain minimum padding equal to height of the **D** tag |
| **Credit appropriately** | Add "© DevHound Project" when used externally |
| **Link to source** | Include `https://devhound.app` when displaying logo online |

### ❌ DON'T

| Violation | Why It's Not Allowed |
|---|---|
| **Add colors to the husky** | Original is monochrome; color changes alter brand identity |
| **Remove or change the D tag** | The **D** collar is the core trademark element |
| **Stretch or skew the logo** | Distortion damages recognizability and professionalism |
| **Use on busy backgrounds** | Low contrast reduces visibility and clarity |
| **Claim ownership** | You may not register or claim the husky design |
| **Alter facial features** | Eyes, nose, ears, and fur lines are protected trademark elements |
| **Combine with competitor logos** | Prevents brand confusion and dilution |

### Approved Color Palette

| Use Case | Hex Code | RGB | CMYK |
|---|---|---|---|
| **Primary Black** | `#000000` | `0, 0, 0` | `0, 0, 0, 100` |
| **Primary White** | `#FFFFFF` | `255, 255, 255` | `0, 0, 0, 0` |
| **Accent Purple** | `#6D4AFF` | `109, 74, 255` | `57, 71, 0, 0` |
| **Gray (fallback)** | `#333333` | `51, 51, 51` | `0, 0, 0, 80` |

### Acceptable Color Combinations

| Combination | Background | Foreground |
|---|---|---|
| Standard | White (`#FFFFFF`) | Black (`#000000`) |
| Dark Mode | Black (`#000000`) | White (`#FFFFFF`) |
| Accent Highlight | White | Purple (`#6D4AFF`) for secondary elements only |
| Grayscale Print | White | Gray (`#333333`) acceptable for low-res output |

**Note:** The husky logo itself should remain black-and-white. Accent purple may be used for surrounding UI elements but should not fill the husky silhouette.

## Trademark Information

### Protected Elements

The following are **trademarked intellectual property** of the DevHound project:

1. **Husky mascot design** — the specific facial structure, fur lines, and profile angle
2. **Triangular D-tag collar** — the pendant with capital **D** letter
3. **"DevHound"** — project name and wordmark
4. **Combined logo lockup** — husky head + project name arrangement

### Not Protected (Fair Use Allowed)

- Generic husky dog images (without the D collar tag)
- The letter **D** alone
- Common canine mascot concepts

### Enforcement

Unauthorized commercial use of the DevHound husky logo will result in:

1. **Cease & desist notice** sent to infringing party
2. **DMCA takedown request** filed with hosting platform
3. **Public disclosure** if unresolved (to warn community)
4. **Legal action** for repeat offenders or large-scale infringement

## Derivative Works Policy

### Community Forks & Projects

If you're creating a fork, derivative, or related project:

| Requirement | Action |
|---|---|
| **Remove trademarks** | Replace or modify the **D**-tag collar to something distinct |
| **Rename project** | Cannot use "DevHound" in your project name |
| **Add disclaimer** | State "Not affiliated with the official DevHound project" |
| **Notify maintainers** | Email `brand@devhound.app` with description of changes |

### Acceptable Modifications

| Modification | Allowed? | Notes |
|---|---|---|
| Change collar tag letter (D → X) | ✅ Yes | Removes trademark association |
| Alter facial expression slightly | ✅ Yes | If D-tag and overall style remain recognizable |
| Add color to husky fur | ⚠️ Conditional | Must remove D-tag and notify maintainers |
| Recreate similar husky style | ⚠️ Conditional | Must be visibly different enough to avoid confusion |
| Remove collar entirely | ✅ Yes | Eliminates trademark element |

### Unacceptable Modifications

| Modification | Allowed? | Reason |
|---|---|---|
| Use exact logo for commercial product | ❌ No | Trademark infringement |
| Sell merchandise with logo | ❌ No | Requires explicit license |
| Claim endorsement by DevHound | ❌ No | Misrepresentation |
| Use on gambling/adult content sites | ❌ No | Brand protection |

## Licensing & Permission Requests

### Open Source Projects

Non-commercial open-source projects may use the logo freely under these conditions:

- Attribution in your project README
- Link back to `https://devhound.app`
- No modification of the **D**-tag collar
- Notify us at `brand@devhound.app`

## Accessibility Guidelines

### For Screen Readers

Always include alt text when embedding the logo:html
<img src="/assets/logo/husky-primary.svg" 
  alt="DevHound logo: stylized husky head with triangular D-tag collar">
### Color Contrast Requirements

| Context | Minimum Ratio | Recommended |
|---|---|---|
| Text on logo background | 4.5:1 | 7:1 |
| Logo on page background | 3:1 | 4.5:1 |
| Interactive elements (buttons) | 3:1 | 4.5:1 |

### Motion Considerations

Do not animate the logo in ways that could trigger vestibular disorders:

- ❌ Rapid flashing or strobing
- ❌ Continuous rotation
- ✅ Subtle fade-in/out transitions are acceptable

## Examples of Correct Usage

### ✅ Good Examples

| Scenario | Implementation |
|---|---|
| Website header | Centered black husky logo on white navigation bar |
| GitHub README | Logo in top-left corner with "DevHound" text beside it |
| Presentation slide | Logo in bottom-right footer with clear space |
| Business card | Small favicon version (16×16mm) on front, full logo on back |
| T-shirt design | Large centered logo with adequate margin around edges |

### ❌ Bad Examples

| Scenario | Problem |
|---|---|
| Colored husky with rainbow gradient | Alters trademarked design |
| Husky on busy photograph background | Poor legibility, no clear space |
| Stretched horizontally logo | Damaged proportions |
| Removed D-tag for "simpler look" | Actually loses trademark element (confusion risk) |
| Logo with competitor brand nearby | Creates false association |

## Contact & Reporting

### Report Violations

If you discover unauthorized use of the DevHound husky logo:

1. Document the infringing material (screenshots, URLs)
2. Email `brand@devhound.app` with subject "Trademark Violation Report"
3. Include:
   - Your name and affiliation
   - Infringing party details
   - Description of violation
   - Evidence attachments

### Request Clarification

Uncertain whether your use case is permitted? Contact us before proceeding:Email:    brand@devhound.app
Subject:  Brand Usage Question – [Your Project Name]
Body:     - Describe intended use
- Include mockup/design preview
- Specify timeline and distribution scope
